Recent application logs are buffered in RAM and uploaded after reconnecting. Overflow is reported; RAM-only lines can be lost on restart. The server retains up to 5,000 lines per device. Trip filters use the trip ID captured with each line. Boot-ROM and low-level library output remain available through USB Serial Monitor.
